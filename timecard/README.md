# 従業員タイムカードアプリ

Googleスプレッドシート + Google Apps Script(GAS)で動くシンプルなタイムカードです。
スマホ・PCのブラウザから「出勤」「退勤」を打刻すると、スプレッドシートに自動で記録されます。

## 勤務ルール

| 項目 | 内容 |
| --- | --- |
| 定時 | 8:00〜17:00 |
| 休憩 | 12:00〜13:00(1時間)→ 所定内労働は最大8時間 |
| 早出 | 8:00より前の出勤分(15分単位・切り捨て) |
| 残業 | 17:00以降の勤務分(15分単位・切り捨て) |
| 月次集計 | 毎月1日の朝6時台に前月分を自動集計 |

15分単位の例:
- 7:40 出勤 → 早出 15分(20分のうち15分単位で切り捨て)
- 17:50 退勤 → 残業 45分
- 17:10 退勤 → 残業 0分(15分に満たないため)

## シート構成

セットアップ時に自動で2つのシートが作られます。

- **打刻記録** … 1日1人1行。日付・氏名・出勤/退勤時刻・所定内・早出・残業・就業時間
- **月次集計** … 毎月1日に前月分を従業員ごとに集計(出勤日数・各時間・合計)

## セットアップ手順(約10分)

1. **スプレッドシートを新規作成**
   [sheets.new](https://sheets.new) を開き、名前を「タイムカード」などにします。

2. **Apps Script を開く**
   メニューの「拡張機能」→「Apps Script」をクリックします。

3. **コードを貼り付け**
   - エディタに最初からある `コード.gs` の中身をすべて消し、このフォルダの **`Code.gs`** の内容を貼り付けます。
   - 左側の「＋」→「HTML」でファイル名を **`index`** にして作成し、このフォルダの **`index.html`** の内容を貼り付けます。
   - 保存(Ctrl+S / Cmd+S)します。

4. **初期セットアップを実行**
   エディタ上部の関数選択で **`setup`** を選び「実行」をクリックします。
   初回は権限の承認画面が出るので許可してください。
   → シート2枚の作成と、毎月1日の自動集計トリガーの登録が行われます。

5. **Webアプリとして公開**
   - 右上の「デプロイ」→「新しいデプロイ」
   - 種類の選択(歯車アイコン)→「ウェブアプリ」
   - 「アクセスできるユーザー」を選択
     - 社内のGoogleアカウントのみ → 「Google アカウントを持つ全員」など組織に合わせて
     - 誰でも打刻できるようにする → 「全員」
   - 「デプロイ」をクリックし、表示された **WebアプリのURL** を従業員に共有します。

6. **打刻する**
   URLを開き、氏名を入力して「出勤」「退勤」ボタンを押すだけです。
   氏名はブラウザに記憶されるので、2回目以降は入力不要です。

## 月次集計について

- 毎月1日の朝6時台に**前月分**が自動で「月次集計」シートに追記されます。
- 手動で集計し直したい場合は、Apps Script エディタで `aggregateMonth(年, 月)` を実行してください。
  例: 2026年5月分 → `aggregateMonth(2026, 5)`
- 同じ年月を再集計すると古い行は自動で置き換えられます。

## 注意事項

- 1人につき1日1回の出勤・退勤を想定したシンプルな仕様です(打刻忘れはシートを直接修正してください)。
- 退勤打刻がない日の記録は月次集計の対象外になります。
- タイムゾーンは日本時間(Asia/Tokyo)固定です。
